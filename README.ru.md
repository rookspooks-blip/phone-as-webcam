# Lensbridge

**Телефон (iPhone или Android) как веб-камера и микрофон для компьютера.** Открытый код, только локальная сеть (Wi-Fi или USB), шифрование, без облака, телеметрии и магазинов приложений: всё ставится из GitHub Actions / Releases вручную.

[English version](README.md) · [Архитектура](docs/ARCHITECTURE.md) · [Протокол](docs/PROTOCOL.md) · [Ручное тестирование](docs/TESTING.md)

![Десктоп-приложение, подключённое к симулятору телефона](docs/images/desktop-app.png)

*Скриншот: десктоп-клиент на Linux, подключён к `lb-sim` (симулятору телефона) по mDNS; превью H.264, 30 к/с, локальная задержка ≈5 мс.*

## Что умеет

- Видео с камеры телефона (H.264, аппаратный кодер) и звук с микрофона (PCM 48 кГц) на ПК.
- Подключение: Wi-Fi (ввод IP, автообнаружение Bonjour/mDNS, пейринг по QR) и USB (iPhone — через usbmuxd, Android — через `adb forward`; клиент делает это сам).
- Выбор любой камеры/объектива, всех разрешений и FPS, которые отдаёт устройство (списки строятся динамически), битрейт, зум, фонарик, зеркалирование, фокус и экспозиция по клику на превью, компенсация экспозиции.
- Экономия батареи: Android — работа с выключенным экраном (служба переднего плана `camera|microphone` + WakeLock + WifiLock); iOS — максимальное затемнение (см. ограничения).
- Шифрование ChaCha20-Poly1305 с ключом из QR-кода, приём только из локальной сети.
- Windows: виртуальная камера **«Lensbridge Camera»** (DirectShow) для Zoom, Discord, Teams, OBS, браузеров; звук как микрофон — через VB-Cable.
- Простой просмотр в браузере: `http://IP-телефона:4747/video` (MJPEG, без шифрования, выключен по умолчанию).
- Автопереподключение, обработка обрыва сети, звонков, смены ориентации; статистика (FPS, битрейт, задержка, батарея, нагрев) и кнопка «Диагностика».

## Быстрый старт

### Где взять файлы

Пока нет релиза: **GitHub → Actions → CI → последний зелёный запуск → Artifacts** (нужен вход в GitHub). После тега `v*` те же файлы и `SHA256SUMS` появятся в **Releases**.

| Файл | Для чего |
|---|---|
| `Lensbridge-windows-x64.zip` | Клиент для Windows 10/11 + драйвер камеры |
| `Lensbridge-macos-universal.dmg` | Клиент для macOS (Intel и Apple Silicon) — превью и звук, без виртуальной камеры |
| `Lensbridge-linux-x64.tar.gz` | Клиент для Linux — превью и звук, без виртуальной камеры |
| `Lensbridge-ios-unsigned.ipa` | iPhone, установка через Sideloadly / AltStore / SideStore |
| `Lensbridge-android.apk` | Android 8+ |

### iPhone + Windows 10 (≈5 минут)

1. **Windows.** Распакуйте `Lensbridge-windows-x64.zip`. Правый клик по `install-vcam.cmd` → «Запуск от имени администратора» (регистрирует камеру «Lensbridge Camera»). Запустите `lensbridge.exe`.
   SmartScreen скажет «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае» (программа не подписана платным сертификатом).
2. **iPhone.** Установите [Sideloadly](https://sideloadly.io) на Windows, подключите iPhone кабелем, перетащите `Lensbridge-unsigned.ipa`, войдите своим Apple ID (бесплатным). На iPhone: «Настройки → Конфиденциальность и безопасность → Режим разработчика» → включить (перезагрузка); «Настройки → Основные → VPN и управление устройством» → доверять своему Apple ID.
3. Откройте Lensbridge на iPhone, разрешите камеру, микрофон и доступ к локальной сети.
4. **Пейринг.** На ПК: «Показать QR для телефона». На iPhone: «Сопрячь с ПК (сканировать QR)».
5. На ПК в списке «Телефоны» нажмите на iPhone (или введите его IP из приложения). Появится превью.
6. В Zoom / Discord / OBS / браузере выберите камеру **«Lensbridge Camera»**.
7. **Микрофон** (по желанию): установите [VB-Cable](https://vb-audio.com/Cable/), в Lensbridge выберите «Звук телефона → CABLE Input», а в Zoom — микрофон «CABLE Output».

**По USB:** установите «Устройства Apple» (Microsoft Store) или iTunes — они ставят службу Apple Mobile Device. Подключите iPhone кабелем, нажмите «Доверять». В списке появится «iPhone (USB)». Задержка по USB ниже и не зависит от Wi-Fi.

**Подпись бесплатным Apple ID живёт 7 дней.** Потом приложение перестаёт запускаться — переустановите его через Sideloadly (в нём есть автопродление, когда ПК и iPhone в одной сети) или используйте AltStore / SideStore.

### Сборка iOS-приложения самому (Intel Mac, macOS 15.7)

На macOS 15.7 последняя доступная версия — **Xcode 26.3** (Xcode 26.4+ требует macOS 26, Xcode 27 — Apple Silicon). Её хватает: приложение рассчитано на iOS 15+ и запускается на iOS 27.

```bash
brew install xcodegen
cd mobile/ios
cat > Config/Local.xcconfig <<'EOF'
LB_TEAM_ID = ABCDE12345            // ваш Team ID (Xcode → Settings → Accounts)
LB_BUNDLE_ID = com.yourname.lensbridge   // любой уникальный
EOF
xcodegen
open Lensbridge.xcodeproj   # выберите iPhone и нажмите Run
```

Если Xcode 26.3 откажется ставить приложение на iPhone с iOS 27 («device not supported»), соберите архив (Product → Archive → Distribute → Custom → Development) или возьмите `.ipa` из CI и установите через Sideloadly.

### Android + Windows

1. Скачайте `Lensbridge-android.apk` на телефон, разрешите «Установку из неизвестных источников» для браузера или файлового менеджера, установите.
2. Откройте приложение, разрешите камеру, микрофон и уведомления. Нажмите «Отключить оптимизацию батареи».
3. Дальше — как для iPhone: пейринг по QR, выбор телефона в списке, «Lensbridge Camera» в приложениях.
4. **По USB:** включите «Для разработчиков → Отладка по USB», установите [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) (положите `adb` в PATH или в папку `platform-tools` рядом с `lensbridge.exe`) и подключите кабель. Телефон появится как «… (USB)».
5. Экран телефона можно выключить кнопкой питания — трансляция продолжится.

### macOS

- **iPhone + Mac:** используйте встроенную **«Камеру Continuity»** (iOS 16+, macOS 13+, тот же Apple ID). Она работает как камера и микрофон во всех приложениях — лучше, чем можно сделать сторонней программой без платной подписи Apple.
- **Клиент Lensbridge для Mac** (`.dmg`) показывает превью и может выводить звук в [BlackHole](https://github.com/ExistentialAudio/BlackHole) (тогда он становится микрофоном). **Своей виртуальной камеры на macOS нет:** CoreMediaIO Camera Extension загружается только с подписью Developer ID ($99/год). Можно захватить окно Lensbridge в OBS и включить OBS Virtual Camera.
- Программа не нотаризована: после копирования в «Программы» выполните `xattr -dr com.apple.quarantine /Applications/Lensbridge.app` или откройте через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

## Ограничения (без прикрас)

- **iOS не даёт камеру приложениям в фоне** — так устроена система, обойти нельзя. Lensbridge должен оставаться открытым. Блокировка экрана, сворачивание или входящий звонок прерывают передачу, после возврата она восстанавливается сама. Чтобы беречь батарею, нажмите «Затемнить экран»: яркость падает до минимума, на чёрном OLED-экране iPhone 13 Pro пиксели почти не потребляют энергию.
- **Windows:** своего драйвера микрофона нет — нужна подпись Microsoft с EV-сертификатом. Используйте VB-Cable. Камеру DirectShow **не видят** приложение «Камера» Windows и некоторые программы, работающие только через Media Foundation.
- **Виртуальная камера отдаёт максимум 1920×1080** (большее разрешение уменьшается), форматы YUY2 и RGB24, 5–60 к/с.
- **Android:** часть прошивок (Xiaomi, Huawei, Samsung, OnePlus) убивает фоновые службы. Отключите оптимизацию батареи, подробности для вашей модели — на [dontkillmyapp.com](https://dontkillmyapp.com). Автоповорот по датчику на настоящих устройствах не проверялся; если картинка повёрнута, выберите «Поворот вручную».
- **Linux-клиент** пока без виртуальной камеры (v4l2loopback не реализован в этой сборке): работают превью и звук.
- Задержка зависит от сети: по Wi-Fi 5 ГГц ожидается 60–120 мс, по USB — меньше. На 2,4 ГГц или при слабом сигнале — больше; снизьте разрешение или битрейт.

## FAQ

**ПК не видит телефон в списке.** Оба устройства должны быть в одной сети (не гостевой, без «изоляции клиентов»). Брандмауэр Windows может блокировать mDNS (UDP 5353) — введите IP вручную (он показан в приложении на телефоне). На iPhone проверьте «Настройки → Lensbridge → Локальная сеть».

**«Телефон не знает этот ПК».** Сделайте пейринг: на ПК «Показать QR для телефона», на телефоне «Сопрячь с ПК». После «Новый ключ» на ПК все телефоны надо сопрячь заново.

**В Zoom нет камеры «Lensbridge Camera».** Запустите `install-vcam.cmd` от администратора и перезапустите Zoom. В Lensbridge должно быть написано «Драйвер камеры установлен», а флажок «Виртуальная камера» — включён.

**Камера в Zoom показывает «Нет сигнала».** Lensbridge на ПК не запущен или не подключён к телефону. Камера показывает заставку, а не исчезает, чтобы Zoom не терял устройство.

**Картинка зеркальная или нет.** Zoom и Teams сами зеркалят ваше превью только для вас, собеседники видят правильно. Флажок «Зеркалить изображение» в Lensbridge меняет картинку для всех.

**Звук трещит или отстаёт.** Используйте 5 ГГц или USB. Звук идёт через буфер около 60 мс, отставание выше 200 мс сбрасывается автоматически.

**Телефон греется.** Снизьте разрешение (1280×720) и FPS (30), держите телефон на зарядке не под прямым солнцем. Индикатор «нагрев» есть в строке состояния ПК.

**Безопасно ли?** Видео шифруется ключом, который передаётся только через QR-код на экране вашего ПК. Подключение возможно только из локальной сети. HTTP-просмотр (порт 4747) не шифруется и выключен по умолчанию.

## Сборка из исходников

| Часть | Команда |
|---|---|
| Десктоп (Rust 1.88+) | `cd desktop && cargo run --release -p lensbridge` (Linux: `sudo apt install libasound2-dev`) |
| Симулятор телефона | `cargo run --release -p lb-sim -- --uri "<ссылка из «Показать QR → Скопировать ссылку»>"` |
| Тесты | `cd desktop && cargo test --workspace` |
| Драйвер камеры Windows | `cmake -S drivers/windows/dshow-filter -B build -A x64 && cmake --build build --config Release` |
| iOS | см. выше (XcodeGen) |
| Android | `cd mobile/android && ./gradlew assembleRelease` (JDK 17, Android SDK) |
