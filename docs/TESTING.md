# Ручное тестирование

Автоматически в CI проверяются: протокол и шифрование (Rust, Swift, Java/Kotlin — общий тестовый вектор), сквозные тесты «клиент ↔ симулятор телефона» (видео, звук, смена разрешения, переподключение, неверный ключ), сборка всех артефактов. Всё, что связано с реальным железом, проверяется по этому списку. Отмечайте результат и прикладывайте отчёт из «Диагностика → Скопировать отчёт».

## 0. Без телефона (5 минут, любая ОС)

- [ ] `lb-sim --uri "<ссылка из «Показать QR → Скопировать ссылку»>"` запущен на том же ПК или в сети.
- [ ] Симулятор появляется в списке «Телефоны» (mDNS), по клику идёт превью с движущейся полосой.
- [ ] Смена «Разрешение» на 1280×720 — превью меняется, в строке состояния 1280×720.
- [ ] Остановить `lb-sim` → «нет связи», «нет сигнала»; запустить снова → подключение само за ≤ 5 с.
- [ ] «Новый ключ…» → состояние «не сопряжено».

## 1. Windows 10/11: виртуальная камера

- [ ] `install-vcam.cmd` от администратора → «Камера … установлена». В Lensbridge: «Драйвер камеры установлен».
- [ ] Без подключённого телефона: в OBS (Источник → Устройство захвата видео → «Lensbridge Camera») видна заставка «Нет сигнала».
- [ ] С телефоном: картинка в OBS, Zoom, Discord, Chrome (`https://webcamtests.com` или meet.google.com), Teams.
- [ ] Разрешения 1280×720, 1920×1080, 640×480 в OBS (свойства устройства) — картинка вписана с полосами при другом соотношении.
- [ ] 32-битное приложение (если есть) видит камеру (`lensbridge_vcam_x86.dll`).
- [ ] Закрыть Lensbridge при открытом Zoom → Zoom не падает, показывает заставку; запустить снова → картинка вернулась.
- [ ] `uninstall-vcam.cmd` → камера пропала из списков.

## 2. Звук

- [ ] Установлен VB-Cable; в Lensbridge «Звук телефона» → «CABLE Input» отмечен «← микрофон для звонков».
- [ ] В Zoom микрофон «CABLE Output», индикатор громкости реагирует на голос у телефона.
- [ ] Рассинхрон губ и звука на глаз < 100 мс; 30 минут без нарастания задержки (в «Диагностике» буфер звука около 60 мс, опустошений мало).

## 3. iPhone (iOS 15–27)

- [ ] Установка: Xcode (бесплатный Apple ID) или Sideloadly с `.ipa` из CI. Режим разработчика включён.
- [ ] Первый запуск: запросы камеры, микрофона, локальной сети.
- [ ] Пейринг по QR → ПК в списке «Сопряжённые ПК».
- [ ] Wi-Fi: ПК находит iPhone автоматически; ручной ввод IP тоже работает.
- [ ] USB (Windows с «Устройствами Apple» или macOS): «iPhone (USB)» в списке, подключение, задержка ниже, чем по Wi-Fi.
- [ ] Объективы: широкий, сверхширокий, телевик, фронтальная, «все объективы (авто)» с зумом 0.5–15×.
- [ ] Все разрешения из списка, 30 и 60 к/с; битрейт 1–20 Мбит/с меняет качество.
- [ ] Фонарик; клик по превью фокусирует и экспонирует в точке (в альбомной и портретной ориентации).
- [ ] Поворот телефона: в режиме «Авто» картинка на ПК остаётся правильной; «Альбомная» / «Портретная» фиксируют ориентацию.
- [ ] «Затемнить экран» (на телефоне и с ПК) → чёрный экран, трансляция идёт 30 минут, двойное касание — выход.
- [ ] Сворачивание приложения → ПК показывает событие «прервано», заставку; возврат → видео само восстановилось.
- [ ] Входящий звонок во время трансляции → прерывание и восстановление после звонка.
- [ ] Выключить Wi-Fi на телефоне на 10 с → переподключение ≤ 5 с после возврата сети.
- [ ] «Просмотр в браузере» → `http://IP:4747/` открывается на ПК; с выключенным флажком порт закрыт.

## 4. Android (8–15+)

- [ ] Установка APK, разрешения, уведомление «Lensbridge — Ожидание подключения ПК».
- [ ] Пейринг по QR (ZXing), Wi-Fi-подключение, mDNS.
- [ ] USB: `adb` найден, «… (USB)» в списке, подключение через `adb forward`.
- [ ] Все камеры (id, f=… мм), разрешения, FPS из списка; зум, фонарик, EV, фокус по клику.
- [ ] **Экран выключен кнопкой питания** — трансляция продолжается 30 минут (с отключённой оптимизацией батареи).
- [ ] Ориентация: «Авто» — правильная картинка в портретной и альбомной; при ошибке «Поворот вручную» исправляет; фронтальная камера не зеркальная (флажок).
- [ ] Другое приложение открывает камеру → событие «камера занята», после закрытия — автоматическое восстановление.
- [ ] Звонок → звук микрофона заглушается системой, после звонка возвращается.
- [ ] Wi-Fi off/on → переподключение.

## 5. Производительность

- [ ] Задержка «стекло-в-стекло»: снимайте телефоном секундомер с миллисекундами на мониторе ПК рядом с превью, сфотографируйте оба. Цель: Wi-Fi 5 ГГц < 150 мс, USB < 100 мс. Запишите модель телефона, разрешение, FPS, битрейт.
- [ ] В строке состояния «задержка ≈…» (оценка «захват → декодирование на ПК») стабильна, без роста за 30 минут.
- [ ] Нагрев: 30 минут 1080p30 — в строке состояния нет «нагрев: serious/critical».
