## Часть 0. Скачать файлы

**Проще всего — из релиза (вход в GitHub не нужен):** https://github.com/rookspooks-blip/phone-as-webcam/releases/latest — там `Lensbridge-windows-x64.zip`, `Lensbridge-unsigned.ipa`, `Lensbridge-macos-universal.dmg`, `Lensbridge-android.apk`, `Lensbridge-linux-x64.tar.gz` и `SHA256SUMS`.

Самые свежие сборки после каждого изменения — в Actions:

1. Откройте https://github.com/rookspooks-blip/phone-as-webcam и войдите в свой аккаунт GitHub (без входа скачать артефакты нельзя).
2. Вкладка **Actions** → слева **CI** → верхний запуск с **зелёной галочкой**.
3. Внизу страницы, в блоке **Artifacts**, скачайте:
   - `Lensbridge-windows-x64` — для Windows;
   - `Lensbridge-ios-unsigned` — приложение для iPhone;
   - `Lensbridge-macos-universal` — для Mac (по желанию, см. часть 2).
4. GitHub отдаёт каждый артефакт ещё одним zip-архивом. Распакуйте его, внутри лежит сам файл (`.zip`, `.ipa` или `.dmg`) и файл `.sha256` с контрольной суммой.

> Артефакты хранятся 90 дней. После релиза (тег `v0.1.0`) те же файлы будут постоянно лежать в разделе **Releases**.

## Часть 1. iPhone + Windows 10

Займёт 20–30 минут в первый раз. Потом запуск — 10 секунд.

### 1.1. Подготовка Windows (один раз)

**а) iTunes — нужен и для установки приложения на iPhone, и для подключения по USB.**
Скачайте iTunes **с сайта Apple** (apple.com/itunes → «Windows» → «Download iTunes for Windows (64-bit)»), а не из Microsoft Store: Sideloadly работает с версией с сайта. Установите и перезагрузите ПК. Вместе с iTunes ставится служба **Apple Mobile Device Service**, через неё Lensbridge видит iPhone по кабелю. По той же причине поставьте **iCloud для Windows с сайта Apple** — его требует Sideloadly.

**б) VB-Cable — чтобы звук телефона стал микрофоном (если микрофон не нужен, пропустите).**
1. https://vb-audio.com/Cable/ → Download → распакуйте архив.
2. Правый клик по `VBCABLE_Setup_x64.exe` → «Запуск от имени администратора» → **Install Driver**.
3. Перезагрузите ПК.
4. Проверка: «Параметры → Система → Звук» — появились «CABLE Input» (вывод) и «CABLE Output» (ввод). **Не делайте «CABLE Input» устройством вывода по умолчанию**, иначе пропадёт звук в колонках.

### 1.2. Установка Lensbridge на Windows

1. Правый клик по `Lensbridge-windows-x64.zip` → «Свойства» → внизу поставьте галочку **«Разблокировать»** → ОК. Так Windows не будет блокировать каждый файл из архива.
2. Распакуйте архив, например в `C:\Lensbridge`. Внутри:
   ```
   lensbridge.exe        — программа
   lb-sim.exe            — симулятор телефона (для проверки без телефона)
   install-vcam.cmd      — установка виртуальной камеры
   uninstall-vcam.cmd    — удаление
   vcam\lensbridge_vcam.dll, vcam\lensbridge_vcam_x86.dll — драйвер камеры
   ```
3. **Установите виртуальную камеру:** правый клик по `install-vcam.cmd` → «Запуск от имени администратора» → «Да» в окне UAC. Должно появиться «Камера "Lensbridge Camera" установлена». Это делается один раз. Папку после этого **не перемещайте** (Windows запоминает путь к драйверу); если переместили — запустите скрипт снова.
4. Запустите `lensbridge.exe`.
   - **SmartScreen** («Windows защитила ваш компьютер») → «Подробнее» → «Выполнить в любом случае». Предупреждение появляется потому, что программа не подписана платным сертификатом.
   - **Брандмауэр** спросит про доступ к сети → отметьте **«Частные сети»** → «Разрешить доступ». Без этого не будет работать автопоиск телефона.
5. В правой колонке «Выход» должно быть написано **«Драйвер камеры установлен»** зелёным, а флажок «Виртуальная камера «Lensbridge Camera»» — включён.

> **Проверка без телефона (по желанию, 1 минута).** В Lensbridge: «Показать QR для телефона» → «Скопировать ссылку». Откройте командную строку в папке и выполните `lb-sim.exe --uri "вставьте ссылку"`. В списке «Телефоны» появится симулятор; нажмите на него — в превью пойдёт тестовая картинка. Значит, ПК-часть и камера работают. Закройте `lb-sim`.

### 1.3. Установка приложения на iPhone (через Sideloadly)

На iOS 27 это самый надёжный путь с Windows.

1. Скачайте Sideloadly для Windows: https://sideloadly.io → установите.
2. Подключите iPhone кабелем, разблокируйте его. На iPhone нажмите **«Доверять этому компьютеру»** и введите код-пароль.
3. В Sideloadly:
   - сверху выберите свой iPhone;
   - перетащите `Lensbridge-unsigned.ipa` в окно (или нажмите на значок IPA);
   - в поле **Apple account** введите свой Apple ID (можно бесплатный; можно завести отдельный);
   - нажмите **Start**, введите пароль Apple ID и при необходимости код двухфакторной проверки.
   - Дождитесь «Done».
4. **Режим разработчика на iPhone** (нужен для любых установленных не из App Store приложений):
   «Настройки → Конфиденциальность и безопасность → Режим разработчика» → включить → «Перезагрузить» → после перезагрузки подтвердить «Включить».
   (Пункт появляется только после того, как на телефон поставили такое приложение.)
5. **Доверие сертификату:** «Настройки → Основные → VPN и управление устройством» → ваш Apple ID → «Доверять».
6. На экране «Домой» появится **Lensbridge**.

**Важно про 7 дней.** С бесплатным Apple ID подпись действует 7 дней, потом приложение перестаёт открываться (данные не теряются). Варианты:
- раз в неделю повторите шаг 3 (30 секунд);
- или в Sideloadly включите автопродление (Advanced options → «Automatic refresh» / auto-refresh — ПК и iPhone должны быть в одной Wi-Fi-сети, Sideloadly запущен).
С бесплатным Apple ID одновременно можно держать не больше 3 таких приложений.

### 1.4. Первый запуск на iPhone

1. Откройте Lensbridge и разрешите **камеру**, **микрофон** и **локальную сеть** (вопрос «Найти устройства в локальной сети?» → «Разрешить»).
2. В разделе «Адрес для ПК» появится IP iPhone (например `192.168.1.57 (en0)`). Он пригодится, если автопоиск не сработает.

### 1.5. Сопряжение (один раз)

1. На ПК в Lensbridge: **«Показать QR для телефона»**.
2. На iPhone: **«Сопрячь с ПК (сканировать QR)»** → наведите камеру на QR-код на экране ПК.
3. На iPhone в «Сопряжённые ПК» появится имя компьютера.

QR содержит секретный ключ шифрования — не показывайте его посторонним и не публикуйте скриншоты с ним.

### 1.6. Подключение

**По Wi-Fi.** ПК и iPhone в одной сети (лучше 5 ГГц). В Lensbridge на ПК слева в «Телефоны» появится iPhone — нажмите на него. Если его нет, введите IP из приложения в поле «Вручную» → «Подключить».

**По USB (меньше задержка, не зависит от Wi-Fi, телефон заряжается).** Подключите кабель — в списке появится **«iPhone (USB)»**, нажмите на него. Нужна служба Apple Mobile Device (ставится с iTunes, шаг 1.1а).

Через пару секунд в центре появится превью, внизу — «● iPhone …», разрешение, к/с, задержка, батарея.
Включённая галочка «Подключаться автоматически» означает, что в следующий раз Lensbridge подключится сам.

### 1.7. Рекомендуемые настройки (правая колонка)

| Настройка | Рекомендация |
|---|---|
| Объектив | «Задняя широкоугольная (1×)» — лучшее качество; «все объективы (авто)» — зум 0.5–15× с переключением; «Фронтальная» — если нужно видеть экран телефона |
| Разрешение | 1280×720 для звонков (Zoom/Teams всё равно сжимают до 720p); 1920×1080 для OBS/записи |
| Кадров/с | 30 (60 — только по USB или хорошему 5 ГГц) |
| Мбит/с | 4–6 для 720p, 8–12 для 1080p; по USB можно больше |
| Фокус | «непрерывный»; клик по превью — фокус и экспозиция по точке |
| Затемнить экран телефона | включите — экономит батарею, камера работает |

На iPhone в «Настройки → Ориентация видео» выберите **«Альбомная»**, если телефон стоит горизонтально на штативе, — тогда картинка не будет поворачиваться от случайных движений.

### 1.8. Выбор камеры и микрофона в программах

Lensbridge должен быть запущен, а iPhone подключён (иначе камера покажет «Нет сигнала»).

| Программа | Камера | Микрофон (если поставили VB-Cable) |
|---|---|---|
| **Zoom** | Настройки → Видео → Камера: «Lensbridge Camera» | Настройки → Звук → Микрофон: «CABLE Output (VB-Audio Virtual Cable)» |
| **Discord** | Настройки → Голос и видео → Камера: «Lensbridge Camera» | Устройство ввода: «CABLE Output» |
| **Teams** | Настройки → Устройства → Камера | Микрофон: «CABLE Output» |
| **OBS** | Источники → «+» → «Устройство захвата видео» → «Lensbridge Camera» | «Захват входного аудиопотока» → «CABLE Output» |
| **Браузер** (Meet, Telegram Web) | при запросе доступа выберите «Lensbridge Camera» | «CABLE Output» |

Для звука в Lensbridge справа: **«Звук телефона» → «CABLE Input (VB-Audio Virtual Cable)»** (подписан «← микрофон для звонков»).

Если программа была открыта до установки камеры — перезапустите её. Камеру **не видит** приложение «Камера» Windows — это ожидаемо (оно работает только через Media Foundation), Zoom/Discord/OBS/браузеры видят.

### 1.9. Как ставить iPhone во время звонка

- На подставку или штатив, горизонтально, на зарядку (или по USB — он заряжает).
- **Lensbridge должен оставаться открытым на экране** — это правило iOS, в фоне камера отключается. Нажмите «Затемнить экран» (на телефоне или галочкой с ПК): экран станет чёрным, на OLED iPhone 13 Pro это почти не тратит батарею. Выход — двойное касание.
- Не блокируйте телефон кнопкой: блокировка = приложение в фоне = камера остановится (после разблокировки восстановится сама).
- Входящий звонок на iPhone прервёт камеру, после звонка она вернётся сама.

### 1.10. Обычный запуск (каждый день)

1. Открыть Lensbridge на iPhone (раз в 7 дней — переустановка через Sideloadly, если не включено автопродление).
2. Запустить `lensbridge.exe` на ПК — подключится сам.
3. Открыть Zoom/OBS.

### 1.11. Удаление

`uninstall-vcam.cmd` от имени администратора, удалить папку; VB-Cable удаляется тем же установщиком (Remove Driver).

## Часть 2. iPhone + Intel Mac

На Mac у вас три варианта. **Рекомендую вариант А** — он лучше всего, что может сделать сторонняя программа.

### Вариант А (рекомендуется): встроенная «Камера Continuity»

Apple сама умеет делать из iPhone камеру и микрофон для Mac. Требования выполнены: iPhone 13 Pro с iOS 16+ и Mac с macOS 13+ (у вас 15.7.3), Intel-маки поддерживаются.

1. **Один Apple ID** на iPhone и Mac, с двухфакторной аутентификацией.
2. На обоих включены **Wi-Fi** и **Bluetooth**, устройства рядом.
3. Mac: «Системные настройки → Основные → AirDrop и Handoff» → включить **Handoff**.
4. iPhone: «Настройки → Основные → AirPlay и Continuity» → включить **«Камера Continuity»**.
5. Поставьте iPhone **горизонтально, неподвижно, экраном от себя** (задняя камера к вам), желательно на держатель. Экран можно заблокировать.
6. В Zoom / FaceTime / OBS / браузере выберите камеру **«Камера iPhone …»**, микрофон — **«Микрофон iPhone …»**.
7. Эффекты (Центр внимания, Портрет, Студийный свет) — в «Пункте управления» Mac → «Видеоэффекты». На Intel-маках часть эффектов может быть недоступна.

Плюсы: без установки, без проводов, телефон можно заблокировать, работает во всех программах.

### Вариант Б: клиент Lensbridge для Mac

Нужен, если хотите управление камерой с компьютера, работу по USB или когда Continuity не подходит. **Своей виртуальной камеры на Mac нет** (требуется платная подпись Apple), поэтому Zoom напрямую её не увидит.

1. Откройте `Lensbridge-macos-universal.dmg` → перетащите **Lensbridge** в «Программы».
2. Программа не нотаризована, поэтому снимите карантин. Откройте «Терминал» и выполните:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Lensbridge.app
   ```
   (Или: попробуйте открыть → «Системные настройки → Конфиденциальность и безопасность» → внизу «Всё равно открыть».)
3. Запустите Lensbridge. macOS 15 спросит доступ к **локальной сети** → «Разрешить» (если пропустили: «Конфиденциальность и безопасность → Локальная сеть → Lensbridge»).
4. Сопряжение и подключение — как в шагах 1.5–1.6 (USB на Mac работает без установки чего-либо: usbmuxd встроен в macOS).
5. **Чтобы использовать как камеру в звонке:** установите OBS Studio (obsproject.com), добавьте источник «Захват окна» → окно Lensbridge, обрежьте до превью и нажмите **«Запустить виртуальную камеру»**; в Zoom выберите «OBS Virtual Camera».
6. **Чтобы звук стал микрофоном:** установите BlackHole 2ch (https://existential.audio/blackhole/ или `brew install blackhole-2ch`), в Lensbridge «Звук телефона» → «BlackHole 2ch», в Zoom микрофон «BlackHole 2ch».

### Вариант В: собрать приложение для iPhone на этом Mac (вместо Sideloadly)

Подходит, если не хотите давать Apple ID сторонней программе. Нужно ~25 ГБ свободного места.

**1. Установить Xcode 26.3** (последняя версия для macOS 15.7; из App Store встанет более новая, которая на вашей системе не запустится):
- https://developer.apple.com/download/all/ → войти Apple ID → найти **Xcode 26.3** → скачать `.xip` → открыть (распакуется) → перетащить Xcode в «Программы».
- Запустить Xcode один раз, согласиться с лицензией, дождаться установки компонентов; в окне платформ отметить **iOS**.
- «Xcode → Settings → Accounts» → «+» → Apple ID → войти. Появится команда **«Ваше имя (Personal Team)»**.

**2. Установить Homebrew и XcodeGen** (Терминал):
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install xcodegen git
```

**3. Скачать исходники и указать подпись:**
```bash
git clone https://github.com/rookspooks-blip/phone-as-webcam.git
cd phone-as-webcam
git checkout claude/gallant-brown-32ppke
cd mobile/ios
cat > Config/Local.xcconfig <<'EOF'
LB_TEAM_ID = XXXXXXXXXX
LB_BUNDLE_ID = com.vashe-imya.lensbridge
EOF
xcodegen
open Lensbridge.xcodeproj
```
- `LB_BUNDLE_ID` — любое уникальное имя в формате `com.что-то.lensbridge`.
- **Где взять Team ID:** проще всего — в Xcode откройте проект → цель «Lensbridge» → вкладка **Signing & Capabilities** → в «Team» выберите свою Personal Team; Xcode покажет её. Чтобы значение не терялось при следующем `xcodegen`, впишите ID в `Local.xcconfig`: его видно в «Связке ключей» → сертификат «Apple Development: …» → «Сведения» → поле **«Подразделение» (OU)**.

**4. Запустить на iPhone:**
- подключите iPhone кабелем, «Доверять этому компьютеру»;
- в Xcode сверху выберите свой iPhone вместо симулятора → кнопка ▶ (Run);
- при первом запуске на iPhone включите **Режим разработчика** (как в шаге 1.3.4) и доверьте сертификат (1.3.5).

**Если Xcode пишет, что iOS 27 на устройстве не поддерживается** (Xcode 26.3 вышел раньше iOS 27): установите Sideloadly **для macOS** с sideloadly.io и поставьте `.ipa` из CI — как в части 1.3, только на Mac. Через 7 дней — снова Run в Xcode или переустановка в Sideloadly.

## Часть 3. Если что-то не работает

| Проблема | Что сделать |
|---|---|
| ПК не видит iPhone в списке | Одна сеть (не гостевая); брандмауэр Windows → разрешить Lensbridge в частных сетях; на iPhone «Настройки → Lensbridge → Локальная сеть» включено; введите IP вручную |
| «Телефон не знает этот ПК» | Повторите сопряжение (1.5). После «Новый ключ…» на ПК сопрягать заново |
| «iPhone (USB)» не появляется | Установлен ли iTunes с сайта Apple; нажато ли «Доверять»; другой кабель/порт; в «Поиск: замечания» слева написана причина |
| Нет «Lensbridge Camera» в Zoom | `install-vcam.cmd` от администратора, перезапуск Zoom; папку после установки не перемещать |
| В Zoom «Нет сигнала» | Lensbridge на ПК закрыт или не подключён к телефону; приложение на iPhone свёрнуто |
| Приложение на iPhone не открывается | Прошло 7 дней — переустановите через Sideloadly/Xcode |
| Задержка, рывки | USB вместо Wi-Fi; Wi-Fi 5 ГГц; 1280×720, 30 к/с, 4–6 Мбит/с |
| Звук трещит | USB или 5 ГГц; в Windows не делайте CABLE Input устройством по умолчанию |
| Телефон сильно греется | 720p/30, на зарядке, не на солнце; индикатор «нагрев» в строке состояния |
| Окно Lensbridge чёрное/не открывается на старом ПК | Запуск с OpenGL: в командной строке `set LENSBRIDGE_RENDERER=glow` и затем `lensbridge.exe` |

Если не помогло: в Lensbridge **«Диагностика» → «Скопировать отчёт»** и пришлите текст — по нему видно, на каком шаге проблема. Полный список проверок — [TESTING.md](TESTING.md).
