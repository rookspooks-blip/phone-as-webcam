# Lensbridge (working name)

Use your phone (Android / iOS) as a webcam and microphone for your PC (Windows, Linux, macOS, OBS). Open source, LAN-only, no cloud, no app stores — releases are distributed via GitHub Releases only.

Используйте телефон (Android / iOS) как веб-камеру и микрофон для ПК (Windows, Linux, macOS, OBS). Открытый код, только локальная сеть, без облака и магазинов приложений.

**Status:** architecture under review — no code yet.
